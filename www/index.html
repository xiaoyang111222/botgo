欢迎使用 Agent Shell 独立版

全部数据只存在这台手机里，没有服务器。开始前只要一步：填入你自己的模型 API key。
  1. 选一个提供方（DeepSeek、EXAONE、OpenAI、Claude 等，预设都备好了）
  2. 粘贴你的 API key，点「获取模型」确认连通
  3. 回来直接开聊——多 bot、长期记忆、技能都已就位
